# 课表改造实现说明

基线为上游 v3.3.11（bbb1bb1），功能分支 feature/timetable-redesign。该发布版与 fork 的 master 存在分叉；分支同时包含发布版已有的语音与项目结构改进。

## 使用流程

1. 没有可用旧课表时，启动后进入课表设置向导。填写默认课程、眼保健操时长，按实际作息逐条添加默认课次，填写学科列表。
2. 向导完成后进入周视图；点击课次按钮，以学科下拉框填入课程。点击星期标题可设置独立时刻表或恢复继承默认安排。
3. 点击“保存课表”后生效。窗口关闭前如有修改会提醒。后续从设置中的课程表入口或桌面课表编辑入口进入。
4. 调课选择日期、时间来源星期和课程来源星期，生成预览后逐节改科目。确认后还需在周视图保存；支持载入、覆盖、取消同日调课。
5. 小黑板直接输入文字，可锁定编辑；停止输入 600ms 后自动保存，正常退出前再次保存。导入导出使用 UTF-8 TXT。

## 已确定的实现选择

- 七天周视图，按真实时间定位；手动添加课次，输入开始时间后依默认时长计算结束时间。可再编辑起止时间。
- 调课目前按单个日期生效；单节微调限于学科。课次多于目标时阻止保存并列出多余学科，避免静默截断。
- 眼保健操结束即正式上课时自动关联下一课；当前界面尚未开放“眼保健操结束后经过准备阶段才上课”的手动关联选项。
- 普通课前提醒从上课前“预备铃间隔 + 提前量”开始，直到正式上课；眼保健操可提前启动同一个弹窗。下课提醒默认 60 秒。
- 课前和下课提醒重叠时，课前优先；课前不允许手动提前收起。空白学科不触发提醒。软件不额外播放学校预备铃音频。
- 语音独立开关，单次运行内按日期与课次去重。恢复时显示有效提醒，不补弹过期提醒。
- 新版本自动安装旧上游二进制会覆盖改造，因此取消上游自动更新，手动检查更新改为打开 fork 的发布页。

## 存储与迁移

Schedule.json 保存默认时刻表、独立星期安排、稳定学科 ID、日期例外及三个提醒参数。Blackboard.txt 保存纯文本。两者使用临时文件 + 原子替换，更新时保留 .bak。

首次读取没有 Schedule.json 时，从原 Timetable.json 迁移七天安排，每天保留独立时间。原 JSON 和墨迹文件不删除。旧临时课表仍保存在旧文件中，但不会自动转换成日期例外；请在新调课窗口配置目标日期。

支持新模型 JSON 导入导出、旧 JSON 导入及单一周的 CSES 导入。同一天有多个 CSES 安排时拒绝导入并提示，防止旧转换逻辑静默覆盖。删除学科时确认并清空引用；重命名按稳定 ID 同步。

## 验证与限制

GitHub Actions 在 Windows 上运行提醒时间边界、日期组合、学科重命名、旧数据迁移和 TXT 原子保存测试，再编译 net472 WPF 程序并打包输出。测试使用生产模型与提醒代码。

当前开发机为 macOS；Windows 上的触摸交互、主题、高 DPI、多显示器弹窗位置、实际语音服务、休眠恢复和周视图视觉布局仍需设备实测。编译及逻辑测试通过不等同于这些界面行为已验收。
